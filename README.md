# Missão Espacial - Estação Espacial Orbit

Projeto desenvolvido para a disciplina de Gestão e Qualidade de Software.

## Objetivo da Missão

Desenvolver e homologar um módulo de monitoramento do sistema de suporte de vida da Estação Espacial Orbit, utilizando Git e GitHub para controle de versão.

## Fluxo de Desenvolvimento

O projeto utiliza três camadas:

- **develop:** ambiente utilizado para o desenvolvimento de novas funcionalidades.
- **stage:** ambiente utilizado para testes e homologação das funcionalidades desenvolvidas.
- **main:** ambiente de produção, contendo as funcionalidades já testadas e aprovadas.

O fluxo utilizado no projeto é:

`develop → stage → main`

## Módulo de Suporte de Vida

O módulo realiza o monitoramento de informações essenciais da estação, incluindo:

- Nível de oxigênio;
- Pressão do módulo;
- Sistema de reciclagem de água.
